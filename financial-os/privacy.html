Privacy policy

Financial OS R20 Partition Provisioner. Updated October 12, 2026.

Purpose and operator

Weixin Jiang operates this personal local application to verify structured financial handoffs, maintain an audit trail and review uncertain records.

Google data accessed

With explicit account consent, the reader can access Drive file metadata and content. The configured workflow reads the progress index, committed bundles, journals and original financial statement evidence. These may contain account identifiers, dates, transaction descriptions, amounts and balances. File IDs, parent IDs, hashes and processing counts are used for integrity and recovery.

Use and storage

Data is used for the local application's review, integrity checks, duplicate prevention and audit workflow. Original bytes may be cached on the user's computer; observations, candidates, outcomes and acknowledgments may be retained in a local SQLite database. The live database is not placed in Drive synchronization.

OAuth credentials are held in the connected Windows user's Credential Manager. Raw statement files and the database are local files and are not asserted to be encrypted by this application. A downloaded Desktop client configuration may also remain on the user's computer when the user chooses to retain it.

Sharing and publication

The local reader communicates with Google's authorization and Drive APIs. Separately authorized transport writers may publish immutable operational acknowledgments or artifacts to approved Drive folders. Operational acknowledgments contain identities, hashes, processing outcomes and counts rather than complete statement text. Original sources are not overwritten, moved or shared by this workflow.

The local deterministic reader does not send raw statements to model APIs. Any upstream ChatGPT extraction or other connected application uses its own separately authorized connection and policies. Source content and credentials are not included in public engineering reports or this website. Google user data is not sold or used for advertising.

Use of data received from Google APIs is limited to the application purposes described here and is subject to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and controls

Local cache, audit and recovery records remain until the user manages them; this application does not promise automatic deletion. Revoking Google access stops subsequent authorized access but does not delete local copies. Removing local credentials does not revoke Google's grant. Because clients share an OAuth application, inspect the scope of provider revocation before assuming it affects only one connection.

This website

These static application pages add no analytics, advertising, cookies, forms or external scripts. GitHub Pages may process visitor network information under GitHub's privacy statement. The user's existing personal website may have its own separate features.
