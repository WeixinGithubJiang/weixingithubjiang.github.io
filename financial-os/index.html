Financial OS R20 Partition Provisioner

A personal, local-first financial data application operated by Weixin Jiang. R20 connects structured Google Drive handoffs to a local review and audit workflow.

What the integration does

  • Reads committed JSON bundles, publication journals, progress metadata and their original statement evidence using Google Drive.
  • Checks exact file identity, destination, content hashes and provenance before local processing.
  • Stores observations, candidate records and review results locally. Unresolved facts remain review items.
  • Uses a separate, narrowly scoped connection for explicitly approved transport publication. It does not modify original financial sources or operate brokerage accounts.

Google authorization

The reader requests drive.readonly, which can read files accessible to the connected account. The application restricts its work to the configured Financial OS index and committed source identities. A separate drive.file client retains app-specific transport permissions. It does not request full-Drive write access.

This site contains application information only. It has no login, financial dashboard, upload form or access to the local database. Publishing this site does not activate automatic consumption or financial production services.
